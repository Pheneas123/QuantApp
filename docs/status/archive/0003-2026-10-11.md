## Project overview

QuantPocket is a mobile-first, local-first study PWA spanning mathematics, quantitative finance, programming and machine learning. It uses React 19, TypeScript, Vite 6, KaTeX and `vite-plugin-pwa`, with a restrained dark interface and British English. There is no backend, account system or cloud synchronisation. Navigation uses React state, not URL routes.

Production is at **https://quantpocket.netlify.app**. Earlier iPhone installation/offline use was user-confirmed. The current local release, including Finance and Programming/ML, **has not been deployed**; earlier device checks do not verify this release. Do not commit, push or deploy without explicit authorisation.

## Current functionality

Quick Practice combines category, populated subsection, Easy/Medium/Hard or Mixed, and Practice / Review Incorrect / Review Unsure / Unseen Only. Sessions contain 10, 25 (default), 50 or all eligible questions, sampled without replacement. Questions and choices are shuffled once; choices stay fixed during an attempt. Submit or Not sure records one immutable attempt, locks answers and reveals feedback/explanation; Next advances explicitly. Desktop shortcuts and session summaries work.

Home counts use latest outcomes; full history remains. Accuracy excludes unsure attempts. Confirmed reset clears Quick Practice history. Reference browsing filters category/subsection/type; related concepts open after submission and return without reshuffling or creating another attempt. Production builds precache app data, code, KaTeX and fonts; updates are offered outside active quizzes.
